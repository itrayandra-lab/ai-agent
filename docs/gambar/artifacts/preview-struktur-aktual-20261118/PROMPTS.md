# Preview struktur aktual RAIVERSE

Tiga gambar, masing-masing desktop dan HP: Beranda, Chat, Pekerjaan. Dibuat built-in image_gen. Struktur mengikuti CORE Beranda/Kantor 3D/Chat/Second Brain dan MORE Pekerjaan/Persetujuan/Tim & Divisi/Agent Studio/Ruang Pengetahuan/Pengaturan yang dibaca dari app.js.

Konsep raster, belum implementasi. Logo dan ikon antar gambar masih bervariasi; implementasi wajib memakai SVG asli. Latar navy di luar screenshot hanya papan presentasi. Font raster belum jaminan font asli. Menu Lainnya sengaja ditampilkan agar struktur bisa diperiksa; pada penggunaan awal dapat dilipat. Data, tanggal, dan status adalah ilustrasi. Belum diuji interaksi, keyboard, mobile aktual, dark theme, loading, error. Tidak mengubah website atau visual lock.
