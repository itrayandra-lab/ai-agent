Prinsip yang sudah diputuskan

  1. Satu antarmuka untuk semua orang, tanpa mode, dipandu pilihan tombol seperti ChatGPT.
  2. Depan (kantor 3D, suara, UI) dibekukan; perubahan ada di backend.
  3. Hal teknis hanya di konsol admin untuk pengelola.
  4. Hierarki: Owner, asisten pribadi dan master, manajer divisi (22), staf.
  5. Staf = orang (karakter 3D) + kemampuan inti bersama (sekitar 30) + keahlian khusus.
  6. Staf berjalan native di RAIVERSE; n8n hanya untuk jadwal dan pemicu luar.
  7. Saluran luar: Telegram dan Discord, tiap pengguna sesi sendiri.
  8. Jujur bila sesuatu belum tersambung; tidak memalsukan hasil.
