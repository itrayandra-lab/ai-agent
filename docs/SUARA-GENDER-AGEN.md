# Gender suara agen (dari nama)

Dibuat otomatis dari nama agen AI saat ini. Gender ini hanya dipakai untuk **suara** (medan `voiceGender` di data karyawan), tidak mengubah tampilan 3D.
Untuk mengoreksi satu agen, ubah `voiceGender` di data karyawannya menjadi `female` atau `male`; nilai yang sudah ada tidak pernah ditimpa.

- Agen AI: **170** (cewek **82**, cowok **88**)
- Baris bertanda **Tinjau** adalah nama merek atau nama yang bisa dua-duanya: mohon periksa.

## Variasi suara yang dihasilkan

| | Cewek | Cowok |
|---|---|---|
| Jumlah agen | 82 | 88 |
| Rentang nada suara browser | 1.08 – 1.32 | 0.76 – 0.96 |
| Profil unik suara browser (1 suara) | 24 | 25 |
| Profil unik mesin Microsoft | 25 | 25 |
| Pasangan terdengar berbeda (browser) | 84.7% | 76.9% |
| Pasangan terdengar berbeda (Microsoft) | 96.1% | 96.0% |

Catatan: bila peramban punya beberapa suara Indonesia, tiap agen juga memilih salah satunya, jadi variasi naik. Dalam satu rapat, agen yang terdengar mirip digeser nada dan kecepatannya agar semuanya berbeda.
