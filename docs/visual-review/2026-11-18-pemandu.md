## Persetujuan hash (dijalankan Owner setelah meninjau tampilan)
Hanya berkas dari pekerjaan Pemandu; berkas sesi lain (office3d.js, tts.js, icons.js, browser-view.js, tts-worker.js) disetujui terpisah oleh pemiliknya.
```bash
node -e "const fs=require('fs'),c=require('crypto'),m=JSON.parse(fs.readFileSync('visual-lock.json','utf8'));for(const f of ['public/css/identity.css','public/js/app.js','public/js/views.js','public/js/pemandu-view.js'])m.files[f]=c.createHash('sha256').update(fs.readFileSync(f,'utf8').replace(/\r\n/g,'\n')).digest('hex');fs.writeFileSync('visual-lock.json',JSON.stringify(m,null,2))"
```
